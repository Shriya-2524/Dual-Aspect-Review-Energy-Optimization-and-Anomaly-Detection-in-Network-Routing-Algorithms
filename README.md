# Dual-Aspect Review: Energy Optimization and Anomaly Detection in Network Routing Algorithms

**A Review of Energy-Efficient Routing and Anomaly Detection Techniques in Wireless Sensor Networks (WSNs)**

## Overview

This paper presents a comprehensive review of network routing algorithms, focusing on two key aspects: energy optimization and anomaly detection in Wireless Sensor Networks (WSNs).

It examines how machine learning, artificial intelligence, bio-inspired optimization, swarm intelligence, and innovative network architectures contribute to energy-efficient routing, improved network lifetime, and enhanced security.

The review also explores the potential integration of Reinforcement Learning (RL) and Graph Neural Networks (GNNs) to develop adaptive routing and intelligent anomaly detection frameworks.

## Research Objectives

- Examine existing energy-efficient routing algorithms and their impact on network lifetime and power consumption.
- Study anomaly detection techniques for identifying unusual network behaviour, faults, and potential security threats.
- Compare traditional, machine learning-based, and bio-inspired routing approaches.
- Evaluate algorithms based on energy efficiency, throughput, scalability, reliability, and anomaly detection capabilities.
- Identify research gaps and explore opportunities for integrating intelligent routing and anomaly detection.

## Key Areas Explored

### 1. Energy-Efficient Routing Algorithms

The paper reviews several routing techniques:

- Ant Colony Optimization (ACO)
- Minimum Total Transmission Power Routing (MTPR)
- Conditional Max-Min Battery Capacity Routing (CMMBCR)
- Hybrid Global Search Optimization – Firefly Algorithm (GSO-FF)
- SVM-based Routing
- Artificial Rabbit Optimization (ARO)
- CFA-LEACH
- Reinforcement Learning-based Routing (RL-DSR)
- Cross-layer and Topology-based Approaches
- Blockchain-based Routing

### 2. Anomaly Detection Techniques

The review explores different approaches to detecting abnormal network behaviour:

- Fuzzy Logic and Genetic Algorithm Extensions
- Content-Aware Dynamic Scheduling (CADS)
- Topology and Traffic-Dependent Models
- Graph Neural Network-based Detection (GNN/EGNN)
- Unsupervised Learning using Autoencoders and Local Outlier Factor (LOF)
- Blockchain-based Anomaly Detection
- Hybrid Machine Learning Models
- Reinforcement Learning-based Anomaly Detection

## Comparative Analysis

The reviewed algorithms are compared across the following parameters:

- Energy efficiency and power consumption
- Network lifetime
- Packet delivery and throughput
- Routing adaptability and scalability
- Anomaly detection capabilities
- Computational complexity and implementation challenges

The paper includes graphical comparisons and a comprehensive comparison table highlighting the strengths and limitations of different approaches.

## Future Research Direction

The paper explores a hybrid **Reinforcement Learning–Graph Neural Network (RL-GNN)** framework as a future research direction.

The proposed direction aims to:

- Use Reinforcement Learning for adaptive, real-time route optimization.
- Leverage Graph Neural Networks to understand relationships and spatial dependencies among sensor nodes.
- Improve the identification of subtle and distributed network anomalies.
- Explore federated and distributed learning to reduce computational and communication overhead.
- Evaluate performance using network lifetime, packet delivery ratio, anomaly detection rate, and latency.

*Note: The RL-GNN framework is proposed as future work in this review and has not been presented as an experimentally implemented model.*
